Making your first automobile game? Or Just a small racing simulation game? Grab these high-quality, low poly assets for a great deal. These optimized assets run on very low end mobile devices, and PC too.

The Devil's Work.shop 'Low Poly Auto Racing Car Pack' contains seven auto racing cars (with separate wheels), The Road Pack which has 11 piece, and the Tree Pack which has three types of trees (with separate bark and leaves). All these game assets have been textured, UV mapped, and unwrapped. The mesh and texture (after compression) are very small and can be used in a street racing game. The asset can be easily imported into Unity or an open-source game engine like Superpowers.


3D Asset Specifications
Format: FBX, OBJ, DAE
Texture: PNG, PSD 
Resolution: 2048x2048
UV Mapped: Yes
Unwrapped UV: Yes
